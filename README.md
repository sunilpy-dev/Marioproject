# 🍄 MarioClub Website

A clean and responsive **Mario-themed landing page** built using **HTML and CSS**.  
This project demonstrates core frontend skills including layout structuring, styling, responsiveness, and modern UI design practices.

---

## 🌟 About The Project

The **MarioClub Website** is a static webpage inspired by the Mario universe.  
It is designed to simulate a fan club landing page that showcases:

- A visually appealing hero banner  
- A newsletter sign-up section  
- An image gallery  
- Responsive layout for different screen sizes  

This project was built to practice and demonstrate **real-world website layout creation using pure HTML and CSS** — no frameworks, no libraries, just clean frontend fundamentals.
